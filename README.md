# Sales Data Engineering & Cleaning Pipeline 🚀

## What and Why (Project Synopsis)

This project is a mini data engineering pipeline built for a machine learning programming course. The goal is to take a messy, raw e-commerce dataset and clean it step by step using Python, functions, and object-oriented programming. This makes the data reliable and ready for business insights or machine learning models.

## Quick-Start Guide

python -m venv venv

pip install -r requirements.txt

jupyter notebook

## Data Sources

* **Primary Transactions:** Custom 500-row synthetic e-commerce sales dataset generated locally via Python (`../data/sales_500.csv`).

* **Secondary Metadata:** Added a secondary lookup source for merging and building our final Data Dictionary.
